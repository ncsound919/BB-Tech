01

What Changed from v1

v1 was a strong start but it performed scientific certainty without proving it. A single blended SER score conflated how hard the case was with how well it was executed with what happened to the patient. Below is the precise set of structural changes made in v2.

v1 Had
One blended SER score with multiplier stack
v2 Has
CCI + TES + WSL + OIS computed separately, SPS as a derived summary only
v1 Had
Pressure multipliers as scalar adjustments to a single score
v2 Has
Workload modeled as its own WSL layer — six scored dimensions, not an on/off toggle
v1 Had
Golf tier (Driver/Iron/Wedge/Putter) as the primary classification output
v2 Has
Golf archetype is an interpretive label, not the score itself — clearly separated
v1 Had
Metrics stated as fact without evidence grading
v2 Has
Every data point tagged E1 (measured), E2 (literature), E3 (expert), E4 (simulated)
E1 · Directly Measured E2 · Literature-Derived E3 · Expert-Estimated E4 · Simulation-Based — evidence grade shown on every data point

Adjust any variable and watch four independent subscores respond — then see how SPS is derived from them. This architecture makes the model calibratable against real procedural data and publishable in a validation study.

SPS Formula
SPS = 0.40×TES + 0.25×OIS + 0.20×(100−WSL) + 0.15×(100−CCI) Rationale: privileges execution and outcome integrity, discounts intrinsic burden and workload so operators are not penalized for taking difficult cases.
03

Procedure Playbook

Cards are phase-aware, evidence-tagged, and score-separated. Each card stores: golf archetype, procedure phase sequence, four-score profile, objective metrics with evidence grade, failure modes, and recommended assist. This structure is machine-ingestible for simulation design, training overlay, and future ML benchmarking.

04

Operative State Matrix

States are no longer descriptive flavor. Each state is defined by explicit quantitative trigger conditions on the four subscores so it can fire automatically during simulation playback, real-time procedural monitoring, or post-case review segmentation.

05

Scoring Methodology

SPEAR v2 is a layered assessment architecture, not a single impression score. It borrows structure from validated surgical skill frameworks (OSATS, GRS, NASA-TLX) while preserving the golf translation layer for interpretive, communicative, and training design utility. The result is a model that can be calibrated, challenged, and eventually validated.
