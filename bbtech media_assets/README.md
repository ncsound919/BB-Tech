## Usage Guidelines

1. **Read-Only Originals** – Treat files here as canonical masters. Duplicate them into build-specific folders if you need to edit.
2. **Versioning** – When adding new assets, use descriptive filenames (`2025-01_dashboard-wireframe.png`) and update this README.
3. **Compression & Format** – Prefer lossless PNG for diagrams/screens, MP4 (H.264) for video, and M4A/MP3 for audio storytelling.
4. **Attribution** – Embed credit or licensing info inside PPT/Notion pages that consume these assets.
5. **Distribution** – For public decks or investors, export smaller copies; keep full-resolution masters here for future rework.
